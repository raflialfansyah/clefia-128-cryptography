Demonstrasi Enkripsi CLEFIA-128

Implementasi murni bahasa Python untuk cipher blok CLEFIA-128 (Spesifikasi Sony v1.0 / RFC 6114) yang terverifikasi terhadap vektor uji resmi, dilengkapi eksperimen efek avalanche, kriteria avalanche ketat (SAC), pengukuran waktu eksekusi, serta aplikasi demonstrasi berbasis web.

Keterbatasan Penting & Peringatan Akademis: Aplikasi ini hanya untuk demonstrasi akademis algoritma CLEFIA-128. Gunakan data simulasi, bukan nama pengguna atau kata sandi asli. Enkripsi dalam mode CTR tanpa pemeriksaan autentikasi (tanpa MAC/HMAC) tidak dapat menjamin bahwa data terenkripsi tidak diubah, dan kata sandi terenkripsi bersifat reversibel di server.

  • Hasil Eksperimen Efek Avalanche, SAC & Waktu Eksekusi
