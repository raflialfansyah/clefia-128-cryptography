Demonstrasi Enkripsi CLEFIA-128

Implementasi murni bahasa Python untuk cipher blok CLEFIA-128 (Spesifikasi Sony v1.0 / RFC 6114) yang terverifikasi terhadap vektor uji resmi, dilengkapi eksperimen efek avalanche, kriteria avalanche ketat (SAC), pengukuran waktu eksekusi, serta aplikasi demonstrasi berbasis web.

Keterbatasan Penting & Peringatan Akademis: Aplikasi ini hanya untuk demonstrasi akademis algoritma CLEFIA-128. Gunakan data simulasi, bukan nama pengguna atau kata sandi asli. Enkripsi dalam mode CTR tanpa pemeriksaan autentikasi (tanpa MAC/HMAC) tidak dapat menjamin bahwa data terenkripsi tidak diubah, dan kata sandi terenkripsi bersifat reversibel di server.

Urutan Demonstrasi Akademis

Panduan alur presentasi langkah demi langkah sesuai rancangan demonstrasi CLEFIA-128-CTR:

  1. Verifikasi Matematis (Matematika CLEFIA): Tunjukkan vektor uji publik resmi RFC 6114 beserta jejak lengkap 18 putaran GFN4,18 dan pemutihan awal/akhir.
  2. Pendaftaran & Penyimpanan Terenkripsi (Daftar): Daftarkan akun simulasi pertama, lalu buka Data Terenkripsi untuk menunjukkan bahwa nama pengguna dan kata sandi hanya disimpan sebagai ciphertext CLEFIA-128-CTR dengan nonce acak 12-byte yang berbeda.
  3. Login Pemindaian Dekripsi (Masuk): Keluar lalu masuk kembali (termasuk variasi huruf kapital pada nama pengguna) untuk menjelaskan pendekatan linear decrypt-and-scan tanpa blind index atau hash kata sandi.
  4. Catatan Profil & Isolasi Pemilik (Catatan Profil): Simpan catatan berbahasa Indonesia lebih dari 16 byte (multi-blok CTR), perbarui kata sandi melalui Ubah Kata Sandi untuk melihat nonce baru, lalu uji bahwa kata sandi salah ditolak dan akun simulasi kedua tidak dapat membaca catatan akun pertama.
  5. Hasil Eksperimen & Keterbatasan (Eksperimen): Tampilkan grafik Efek Avalanche, SAC, dan benchmark berlabel Bahasa Indonesia, serta jelaskan batasan mode CTR tanpa pemeriksaan integritas MAC, penyimpanan kata sandi yang reversibel, dan kompleksitas pemindaian O(n).
